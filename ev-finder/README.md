# EV Finder setup
1. Create a Google Apps Script project at https://script.google.com and paste Code.gs.
2. In Project Settings > Script Properties set AFDC_KEY (https://developer.nlr.gov/), ACCESS_TOKEN (a long random personal secret, at least 32 characters), and optionally GOOGLE_KEY (Google Cloud Places API New, billing enabled and API restricted). Set Google API quotas and billing alerts.
3. Deploy > New deployment > Web app > Execute as me > Anyone (anonymous access). The token protects requests, but this is a personal-use bearer token, not full user authentication. Do not share it. If your school/work account prohibits anonymous deployment, use a personal account or a different authenticated backend. Copy the /exec URL.
4. Host the public folder over HTTPS. For Firebase Hosting, install Node.js and run npm install -g firebase-tools, firebase login, firebase projects:list, then from this folder run firebase deploy --only hosting --project YOUR_PROJECT_ID (create a Firebase project and enable Hosting first). Alternatively publish the contents of public to GitHub Pages. Never commit your keys or token.
5. Open the hosted URL. Expand Connection settings, enter the /exec URL and access token, save and allow location. Verify actual results before installing. Apps Script cross-origin redirects may fail in some deployments; if so, a same-origin server proxy is required. Do not disable browser security.
6. Android: Chrome menu > Add to Home screen / Install app. iPhone: Safari Share > Add to Home Screen > Open as Web App if offered.

Location is requested on launch, foreground return and manual refresh; not tracked in background. Radius changes also trigger a search. Preferences and token are stored locally on the phone. GPS and token are sent in HTTPS query parameters to Apps Script, which may be logged by infrastructure; do not use this as a high-security multi-user service. Rotate token if exposed. No location history is intentionally stored by this code.

AFDC pricing is reported text, not guaranteed current. Estimates exclude all additional fees. Availability is optional and conservatively matched by network name and proximity; unmatched stations show unknown. Connector availability is not queue length. Google search is limited to 20 results. Distances are straight-line. The app shell can open offline after caching, but live search requires internet. No API credentials are included. Source syntax checked only; live APIs, CORS and installation require testing after deployment. To update Apps Script, edit the deployment to a new version. For frontend updates, redeploy Hosting and bump the service worker cache version when changing the shell.
